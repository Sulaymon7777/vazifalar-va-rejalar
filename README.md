# yakuniy-loyha-html-css-js

## 📝 Vazifalar va Rejalar Ro'yxati (To-Do List) Internet Dasturi

HTML, CSS va JavaScript texnologiyalari yordamida yaratilgan zamonaviy va qulay **To-Do List** dasturi.

---

### ✨ Asosiy Imkoniyatlar (Features)

- ➕ **Yangi vazifa qo'shish**: Qulay kiritish maydoni va tugma orqali.
- ✅ **Bajarilganlik holatini belgilash**: Bir marta bosish orqali vazifani bajarilgan yoki bajarilmagan holatga o'tkazish.
- 🗑️ **Vazifani o'chirish**: Keraksiz vazifalarni bir zumda o'chirish imkoniyati.
- 💾 **LocalStorage integratsiyasi**: Barcha vazifalar brauzer xotirasida saqlanadi, sahifa yangilansa ham yo'qolmaydi.
- 📊 **Statistika hisoblagichi**: Jami va bajarilgan vazifalar sonini real vaqt rejimida ko'rsatib turish.
- 📱 **To'liq moslashuvchan (Responsive)**: Barcha qurilmalarda (mobil, planshet, kompyuter) mukammal ko'rinish.
- 🎨 **Zamonaviy UI/UX dizayn**: Chiroyli gradientlar, silliq animatsiyalar va zamonaviy uslub.

---

### 🛠️ Ishlatilgan Texnologiyalar

- **HTML5** – Semantik va qulay veb-tuzilma
- **CSS3** – Zamonaviy flexbox, gradientlar, animatsiyalar va responsive dizayn
- **JavaScript (ES6+)** – DOM manipulyatsiyasi va LocalStorage bilan ishlash
